# Apetrechos Calçados — Kit de Logotipos (PNG)

Renderizado com as fontes oficiais da marca — **Playfair Display Bold** (wordmark),
**Playfair Display Bold Italic** (o "e" rosé) e **Inter SemiBold** ("CALÇADOS").
Texto vetorial rasterizado em alta resolução; fundo transparente onde indicado.

| Arquivo | Fundo | Uso |
|---|---|---|
| `apetrechos-logo-principal.png` | Transparente | **Versão preferencial.** Sobre fundos claros. Tinta + "e" rosé + CALÇADOS cinza. |
| `apetrechos-logo-negativa.png` | Transparente | Sobre fundos escuros / tinta. Off-white + "e" rosa claro. |
| `apetrechos-logo-mono-preto.png` | Transparente | Uma cor (preto). Impressão P&B, carimbo, marca d'água. |
| `apetrechos-logo-mono-branco.png` | Transparente | Uma cor (branco). Sobre foto escura, vídeo, aplicações especiais. |
| `apetrechos-logo-reduzida.png` | Transparente | Só o wordmark, sem "CALÇADOS". Para tamanhos pequenos (< 120px). |
| `apetrechos-logo-sobre-rose.png` | Rosé `#BE185D` | Selo/assinatura sobre a cor da marca. |
| `apetrechos-icone.png` | Tinta `#0B0B0F` | Avatar / favicon / app. Ladrilho com "A" rosé. 1024×1024. |

## Regras de uso

- **Área de proteção:** deixe ao redor um respiro mínimo igual à altura da letra "A".
- **Redução mínima:** digital 120px de largura, impresso 24mm. Abaixo disso, use `reduzida`.
- **Não faça:** recolorir o "e", trocar a fonte, condensar, aplicar sombra/contorno ou girar.

## Cores da marca
